ALVR — исправление ошибки порта 8082
=====================================

Скачайте ОДИН файл и запустите:
https://github.com/boterbro/-/raw/main/ALVR-FIX.bat

1. Дважды кликните ALVR-FIX.bat
2. Нажмите «Да» (права администратора)
3. Дождитесь «DONE» — ALVR откроется сам
4. Нажмите Launch SteamVR → на Quest откройте ALVR
